# Digital Clock

## 📌 Project Description
This is a simple **Digital Clock** built using **HTML, CSS, and JavaScript**. The clock displays the current time in **hours, minutes, and seconds**, updating dynamically.

## 🔥 Features
- Displays real-time hours, minutes, and seconds ⏰
- Supports **12-hour and 24-hour formats** 🕰️
- Uses **smooth animations** for better UI experience 🎨
- Fully responsive design 📱
- Easy to integrate into websites 🌐

## 🛠️ Technologies Used
- **HTML** → Structure the clock UI
- **CSS** → Styling and animations
- **JavaScript** → Time updates dynamically

## 🚀 How to Run
1. **Clone the Repository:**
   ```sh
   git clone https://github.com/your-username/digital-clock.git
   ```
2. **Navigate to the Folder:**
   ```sh
   cd digital-clock
   ```
3. **Open `index.html` in your browser.**

```
